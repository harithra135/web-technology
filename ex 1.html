2. Fundamental Computer Network Concepts

  • IP Address: Identifies a device on a network.
  • Router: Transfers data between different networks.
  • Protocol: Rules used for communication.
  • HTTP/HTTPS: Protocols used for web communication.
  • TCP/IP: A collection of protocols used by the Internet.
  • DNS: Converts domain names into IP addresses.

3. URL and Its Structure

A URL identifies the location of a resource on the Internet.

https://www.example.com/products/index.html
  • https: Protocol
  • www: Subdomain
  • example.com: Domain name
  • /products/: Directory
  • index.html: Web page/file

4. Domain Name

A domain name is the human-readable name used to access a website. For example, google.com is a domain name.
